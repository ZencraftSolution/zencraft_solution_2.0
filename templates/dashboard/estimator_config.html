How the estimate is calculated

  1. Hours = project type base hours + hours of each selected feature.
  2. Each platform after the first adds its platform coefficient as a share of those hours.
  3. Hours are multiplied by the design, urgency and team multipliers.
  4. Cost = hours x blended hourly rate x (1 + contingency %), never below the minimum project value.
  5. Displayed range = cost x low factor to cost x high factor, rounded to Rs. 10,000.
  6. Weeks = hours / (suggested team FTE x productive hours per week), shown as a range.

Multiplier fields are JSON objects. Keep every key listed in the default values.
